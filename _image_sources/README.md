# Logo sources

- ICT: https://asg.ict.ac.cn/images/logo.png, linked by https://www.ict.ac.cn/ (retrieved 2026-11-15). Official 147×122 PNG.
- HIT and Cambricon: original high-resolution PNGs retained from this repository.

Run `bash scripts/optimize_logos.sh` to regenerate lossless WebP derivatives.
Display sizes remain in `_sass/_home.scss`; intrinsic dimensions live in `_data/career.json`.
